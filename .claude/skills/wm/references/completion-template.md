# Completion Report Guide

## Completion Report Format

```markdown
## Completion Report

### 1. Pipeline Execution Summary

> Refer to **Agent Execution Log** in Plan document for detailed agent status.

| Item | Status |
|------|--------|
| Overall steps | Completed / Failed |
| Failed steps (if any) | - |

### 2. Change Summary
- [ ] Confirm list of modified files
- [ ] Describe key changes

### 3. Verification Results
- [ ] QA status: Pass / Fail
- [ ] Test results summary

### 4. Follow-up Actions (if any)
- [ ] Whether session restart is needed
- [ ] Items requiring manual verification
```
