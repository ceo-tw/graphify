# Artifact Verification Guide

> **Version**: 1.0.0
> **Purpose**: 3-level verification that generated code is complete and actually works
> **Author**: workflow-manager-plugin
> **Last Updated**: 2026-02-03

---

## Philosophy: Stubs are Lies

Code generated by development agents often **"appears complete but is actually unfinished"**.

### Common Stub Cases

| Stub Type | Example | Problem |
|-----------|---------|---------|
| **Empty Function** | `function createUser() {}` | No actual logic |
| **TODO Comment** | `// TODO: implement validation` | Feature not implemented |
| **Throw Error** | `throw new Error('Not implemented')` | Crashes when called |
| **Mock Data** | `return []` | No actual DB query |
| **Placeholder String** | `const API_KEY = 'xxx'` | Missing configuration |

**Goal of Artifact Verification**: Detect 100% of such stubs to prevent quality degradation

## 3-Level Verification Framework

### Level 1: Exists (Existence Check)

**Purpose**: Verify that planned files/functions/classes have actually been created

| Check Item | Tool | Pass Criteria |
|------------|------|---------------|
| File exists | `ls`, `Glob` | File was created |
| Build success | `bun build`, `tsc` | No compile errors |
| Type check | `tsc --noEmit` | No type errors |
| Lint pass | `eslint`, `shellcheck` | No lint warnings |

**Verification code example**:

```python
# Step 2.8-1: Exists Verification
import os

def verify_exists(task_metadata):
    """Level 1: Existence check"""
    expected_files = task_metadata.get("expected_files", [])

    for file_path in expected_files:
        if not os.path.exists(file_path):
            return {
                "level": "Exists",
                "status": "FAIL",
                "reason": f"File not found: {file_path}"
            }

    # Build check
    build_result = Bash(command="bun run build")
    if build_result.exit_code != 0:
        return {
            "level": "Exists",
            "status": "FAIL",
            "reason": "Build failed",
            "details": build_result.output
        }

    return {"level": "Exists", "status": "PASS"}
```

### Level 2: Substantive (Substantial Implementation)

**Purpose**: Verify that existing files contain real implementation, not stubs

#### 2.1 Minimum Line Count Criteria

| Artifact Type | Minimum Lines | Rationale |
|---------------|---------------|-----------|
| **React Component** | 20 lines | Minimum JSX + logic |
| **API Route** | 15 lines | Request parsing + response |
| **Service Class** | 30 lines | Constructor + 2+ methods |
| **Database Migration** | 10 lines | CREATE TABLE + indexes |
| **Test File** | 25 lines | Setup + 3+ test cases |
| **Config File** | 5 lines | Minimum YAML/JSON config |

**Verification code example**:

```python
def check_minimum_lines(file_path, artifact_type):
    """Minimum line count check"""
    min_lines = {
        "component": 20,
        "api": 15,
        "service": 30,
        "migration": 10,
        "test": 25,
        "config": 5
    }

    with open(file_path, 'r') as f:
        # Exclude empty lines and comments
        code_lines = [
            line for line in f.readlines()
            if line.strip() and not line.strip().startswith('//')
        ]

    actual = len(code_lines)
    expected = min_lines.get(artifact_type, 10)

    if actual < expected:
        return {
            "status": "FAIL",
            "reason": f"Too short: {actual} lines (expected {expected}+)"
        }

    return {"status": "PASS"}
```

#### 2.2 Stub Detection Patterns

**Regex Pattern Library**:

| Pattern Name | Regex | Language | Example |
|--------------|-------|----------|---------|
| **TODO Comment** | `//\s*TODO` | TS/JS | `// TODO: implement` |
| **FIXME Comment** | `//\s*FIXME` | TS/JS | `// FIXME: bug here` |
| **Not Implemented Error** | `throw\s+new\s+Error\(['"](Not implemented|TODO)['"]\)` | TS/JS | `throw new Error('Not implemented')` |
| **Empty Function** | `function\s+\w+\s*\([^)]*\)\s*\{\s*\}` | TS/JS | `function foo() {}` |
| **Empty Arrow Function** | `=>\s*\{\s*\}` | TS/JS | `const foo = () => {}` |
| **Placeholder String** | `['"](?:xxx|placeholder|TBD|FIXME)['"]` | Any | `const key = 'xxx'` |
| **Mock Return** | `return\s+(?:\[\]|null|undefined|\{\})` | TS/JS | `return []` |
| **Pass Statement** | `^\s*pass\s*$` | Python | `def foo(): pass` |
| **Unimplemented Panic** | `unimplemented!\(\)` | Rust | `fn foo() { unimplemented!() }` |

**Verification code example**:

```python
import re

STUB_PATTERNS = {
    "TODO": re.compile(r'//\s*TODO'),
    "FIXME": re.compile(r'//\s*FIXME'),
    "NotImplementedError": re.compile(r'throw\s+new\s+Error\([\'"](?:Not implemented|TODO)[\'"]'),
    "EmptyFunction": re.compile(r'function\s+\w+\s*\([^)]*\)\s*\{\s*\}'),
    "Placeholder": re.compile(r'[\'"](?:xxx|placeholder|TBD|FIXME)[\'"]'),
    "MockReturn": re.compile(r'return\s+(?:\[\]|null|undefined|\{\})\s*;?\s*$'),
}

def detect_stubs(file_path):
    """Level 2: Stub detection"""
    with open(file_path, 'r') as f:
        content = f.read()

    detected = []
    for pattern_name, regex in STUB_PATTERNS.items():
        matches = regex.finditer(content)
        for match in matches:
            line_num = content[:match.start()].count('\n') + 1
            detected.append({
                "pattern": pattern_name,
                "line": line_num,
                "snippet": match.group(0)
            })

    if detected:
        return {
            "level": "Substantive",
            "status": "FAIL",
            "reason": f"Found {len(detected)} stub(s)",
            "details": detected
        }

    return {"level": "Substantive", "status": "PASS"}
```

#### 2.3 Substantive Implementation Check

**Additional verification items**:

| Check | Pass Criteria |
|-------|---------------|
| **Import exists** | At least 1 external module import |
| **Function body** | At least 3 lines of logic |
| **Conditionals/loops** | At least 1 if/for/while |
| **Error handling** | try-catch or if-error pattern exists |
| **Comments** | At least 1 descriptive comment per function (excluding TODO) |

**Verification code example**:

```python
def check_substantive_implementation(file_path):
    """Substantive implementation check"""
    with open(file_path, 'r') as f:
        content = f.read()

    checks = {
        "has_imports": bool(re.search(r'^import\s+', content, re.MULTILINE)),
        "has_conditionals": bool(re.search(r'\b(if|for|while)\b', content)),
        "has_error_handling": bool(re.search(r'\b(try|catch|throw)\b', content)),
        "has_comments": bool(re.search(r'//(?!\s*TODO)', content)),
    }

    failed = [k for k, v in checks.items() if not v]

    if failed:
        return {
            "status": "FAIL",
            "reason": f"Missing: {', '.join(failed)}"
        }

    return {"status": "PASS"}
```

### Level 3: Wired (System Connection)

**Purpose**: Verify that generated code is actually connected to other parts of the system

#### 3.1 Import/Usage Verification

| Artifact | Connection Check | Tool |
|----------|-----------------|------|
| **Component** | Imported in parent component | `Grep("import.*MyComponent")` |
| **API Route** | Registered in router | `Grep("router.get\('/my-route'")` |
| **Service** | Used in Controller | `Grep("new MyService")` |
| **Hook** | Called in component | `Grep("useMyHook")` |
| **Type** | Imported in other files | `Grep("import.*MyType")` |

**Verification code example**:

```python
def verify_wired(artifact_name, artifact_type):
    """Level 3: System connection verification"""

    # Component example
    if artifact_type == "component":
        # Check import in parent component
        usage = Grep(
            pattern=f"import.*{artifact_name}",
            type="tsx",
            output_mode="files_with_matches"
        )

        if not usage.files:
            return {
                "level": "Wired",
                "status": "FAIL",
                "reason": f"{artifact_name} not imported anywhere"
            }

        # Verify actual usage (not just import)
        actual_usage = Grep(
            pattern=f"<{artifact_name}",  # Used as JSX tag
            type="tsx",
            output_mode="content"
        )

        if not actual_usage.matches:
            return {
                "level": "Wired",
                "status": "FAIL",
                "reason": f"{artifact_name} imported but not used"
            }

    # API Route example
    elif artifact_type == "api":
        # Check registration in app.ts or router.ts
        registration = Grep(
            pattern=f"app\\.(get|post|put|delete)\\(['\"].*{artifact_name}",
            type="ts",
            output_mode="content"
        )

        if not registration.matches:
            return {
                "level": "Wired",
                "status": "FAIL",
                "reason": f"API route {artifact_name} not registered"
            }

    return {"level": "Wired", "status": "PASS"}
```

#### 3.2 Core Wiring Patterns

**Required connections by architecture**:

| Architecture | Layer | Must Be Wired To |
|--------------|-------|------------------|
| **Clean Architecture** | Entity | Repository (DI) |
| | Use Case | Controller |
| | Repository Interface | Concrete Implementation |
| **MVC** | Model | Controller |
| | Controller | Route |
| | View | Controller action |
| **Microservices** | Service | API Gateway |
| | Event Publisher | Event Subscriber |

**Verification example (Clean Architecture)**:

```python
def verify_clean_architecture_wiring():
    """Clean Architecture wiring verification"""

    # Check if Use Case is used in Controller
    use_cases = Glob(pattern="**/application/usecases/*.ts")

    for use_case_file in use_cases:
        use_case_name = extract_class_name(use_case_file)

        # Check import in Controller
        controller_usage = Grep(
            pattern=f"import.*{use_case_name}",
            path="src/adapters/controllers/",
            type="ts"
        )

        if not controller_usage.files:
            return {
                "status": "FAIL",
                "reason": f"Use Case {use_case_name} not wired to Controller"
            }

    # Check if Repository Interface is implemented
    repo_interfaces = Glob(pattern="**/application/ports/*.ts")

    for interface_file in repo_interfaces:
        interface_name = extract_interface_name(interface_file)

        # Check implementation in Adapters
        implementation = Grep(
            pattern=f"implements {interface_name}",
            path="src/adapters/repositories/",
            type="ts"
        )

        if not implementation.files:
            return {
                "status": "FAIL",
                "reason": f"Port {interface_name} not implemented in Adapters"
            }

    return {"status": "PASS"}
```

## Verification Matrix

**Complete verification process summary**:

| Level | Check Item | Tool | Action on Failure |
|-------|-----------|------|-------------------|
| **1. Exists** | File exists | `ls`, `Glob` | Re-run dev-executor |
| | Build success | `bun build` | Fix compile errors |
| | Type check | `tsc --noEmit` | Fix type errors |
| | Lint pass | `eslint` | Fix lint warnings |
| **2. Substantive** | Minimum lines | `wc -l` | Request implementation completion |
| | Stub pattern detection | Regex | Remove TODO/FIXME |
| | Substantive implementation | AST analysis | Request logic addition |
| **3. Wired** | Import check | `Grep` | Add connection code |
| | Actual usage check | `Grep` | Implement usage points |
| | Architecture connection | `Grep` + patterns | Add DI configuration |

## Integration with qa Agent

**Reference**: `.claude/agents/qa.md` Step 2.8

The qa agent uses this guide as follows:

```python
# Step 2.8: Artifact Verification (qa.md)
Read(file_path=".claude/skills/wm/rules/policies/guide-artifact-verification.md")

# 1. Level 1: Exists
exists_result = verify_exists(task_metadata)
if exists_result["status"] == "FAIL":
    return {
        "qa_status": "FAIL",
        "level": "Exists",
        "details": exists_result
    }

# 2. Level 2: Substantive
for file_path in task_metadata["expected_files"]:
    # 2.1 Minimum line count
    line_check = check_minimum_lines(file_path, artifact_type)

    # 2.2 Stub detection
    stub_check = detect_stubs(file_path)

    # 2.3 Substantive implementation
    impl_check = check_substantive_implementation(file_path)

    if any([line_check["status"] == "FAIL",
            stub_check["status"] == "FAIL",
            impl_check["status"] == "FAIL"]):
        return {
            "qa_status": "FAIL",
            "level": "Substantive",
            "details": [line_check, stub_check, impl_check]
        }

# 3. Level 3: Wired
wired_result = verify_wired(artifact_name, artifact_type)
if wired_result["status"] == "FAIL":
    return {
        "qa_status": "FAIL",
        "level": "Wired",
        "details": wired_result
    }

# All levels passed
return {
    "qa_status": "PASS",
    "message": "All 3 levels passed",
    "details": {
        "exists": exists_result,
        "substantive": {"line_check": line_check, "stub_check": stub_check, "impl_check": impl_check},
        "wired": wired_result
    }
}
```

## Practical Examples

### Example 1: React Component Verification

**Task**: Create `UserProfileCard` component

```typescript
// ❌ Level 2 FAIL (Stub)
export function UserProfileCard() {
  // TODO: implement
  return null;
}

// ✅ Level 2 PASS (Substantive)
export function UserProfileCard({ user }: UserProfileCardProps) {
  if (!user) {
    return <div>Loading...</div>;
  }

  return (
    <div className="profile-card">
      <Avatar src={user.avatar} />
      <h2>{user.name}</h2>
      <p>{user.bio}</p>
    </div>
  );
}

// ✅ Level 3 PASS (Wired)
// src/app/dashboard/page.tsx:
import { UserProfileCard } from "@/components/user-profile-card";

export default function DashboardPage() {
  return <UserProfileCard user={currentUser} />;
}
```

### Example 2: API Route Verification

**Task**: Create `POST /api/users` endpoint

```typescript
// ❌ Level 2 FAIL (Mock Return)
export async function POST(request: Request) {
  return NextResponse.json({ users: [] });
}

// ✅ Level 2 PASS (Substantive)
export async function POST(request: Request) {
  try {
    const body = await request.json();
    const validatedData = userSchema.parse(body);

    const user = await db.users.create({
      data: validatedData
    });

    return NextResponse.json({ user }, { status: 201 });
  } catch (error) {
    return NextResponse.json(
      { error: "Validation failed" },
      { status: 400 }
    );
  }
}

// ✅ Level 3 PASS (Wired)
// Client-side usage:
const response = await fetch('/api/users', {
  method: 'POST',
  body: JSON.stringify(userData)
});
```
